

# Idea Generator

This project was created during the summer before I entered university — back in my school days.  
It can be considered one of my **first personal projects**, a starting point for my portfolio as a future software engineer.

---

## Project Concept

I wanted to go beyond something as basic as a calculator, so I came up with the idea of an **Idea Generator**.  
It was originally made for my best friend, who loves drawing.  
The purpose of the project is to **store creative ideas** and **generate them randomly** whenever you need inspiration for a new drawing.

---

##  How to Open and Test

I developed this project using **Visual Studio Code**, so the repository includes a folder containing all the necessary files.

To open and run it:

1. Open the folder in **Visual Studio Code** (or any other preferred editor).  
2. Make sure you have **Python installed** and the required **VS Code Python extensions** enabled.  
3. Check that your Python version matches the one used in the project.  
4. Run the main file in your editor or terminal to start testing the generator.

You can also open the files manually using any other IDE or code editor of your choice.
