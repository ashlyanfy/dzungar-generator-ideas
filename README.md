

# Idea Generator

This project was created during the summer before I entered university — back in my school days.  
It can be considered one of my **first personal projects**, a starting point for my portfolio as a future software engineer.

---

## Project Concept

I wanted to go beyond something as basic as a calculator, so I came up with the idea of an **Idea Generator**.  
It was originally made for my best friend, who loves drawing.  
The purpose of the project is to **store creative ideas** and **generate them randomly** whenever you need inspiration for a new drawing.
